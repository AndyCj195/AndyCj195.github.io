API REST en Spring Boot 3, PostgreSQL, Docker & Flutter BLoC

Arquitectura desacoplada con servicios REST en Spring Boot 3, persistencia relacional en PostgreSQL contenedorizada con Docker y cliente móvil reactivo en Flutter (Clean Architecture + BLoC/Provider).

Flutter UI (BLoC / Provider) → Spring Boot 3 REST API → PostgreSQL (Docker) 
@RestController
@RequestMapping("/api/v1/transacciones")
public class TransaccionController {
    private final TransaccionService service;

    public TransaccionController(TransaccionService service) {
        this.service = service;
    }

    @PostMapping
    public ResponseEntity<TransaccionDTO> registrar(@Valid @RequestBody TransaccionRequest req) {
        TransaccionDTO respuesta = service.procesarTransaccion(req);
        return ResponseEntity.status(HttpStatus.CREATED).body(respuesta);
    }
}
